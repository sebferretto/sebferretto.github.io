Blickee Bee

Spawn bees to defend against waves of attackers. Blickee Bee features an auto targeting system and a manual targeting system using mouse tracking, giving the player control over how they handle each wave.

Features

  • Auto and manual targeting systems
  • Wave-based enemy spawning
  • Difficulty scaling per-wave
  • Points system and upgrades
  • Save system to track progress

Swimmy Fihh

Swimmy Fihh plays similarly to "Flappy Bird" with scaling difficulty. Guide your fish through increasingly challenging obstacles as the game speeds up over time. This was the first game I ever made!

Features

  • Responsive UI based on screen-size
  • Playable in browser and on mobile
  • Simple one-button controls
  • Scaling difficulty over time
  • Endless gameplay
